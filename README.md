# Антиспам-бот для Telegram

Бот для группы (или группы комментариев канала). Удаляет рекламу и ссылки,
банит спамеров, мьютит флудеров.

## 1. Создайте бота у @BotFather

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, придумайте имя и username (оканчивается на `bot`).
3. BotFather выдаст токен вида `123456789:AAE...` — скопируйте его.
4. **Важно:** отправьте BotFather команду `/setprivacy`, выберите своего бота
   и нажмите **Disable** — иначе бот не будет видеть обычные сообщения в группе.

## 2. Установка и запуск (Windows)

Нужен Python 3.10+ (https://www.python.org/downloads/, при установке
отметьте галочку **Add Python to PATH**).

```bat
cd C:\Users\User\antispam-bot
pip install -r requirements.txt
```

Вставьте токен в файл `token.txt` (просто одна строка с токеном) — создайте
его рядом с `bot.py`. Затем запустите:

```bat
python bot.py
```

Должна появиться строка `Антиспам-бот запущен.` Пока окно открыто — бот работает.

## 3. Добавьте бота в группу

1. Добавьте бота в группу как обычного участника.
2. Назначьте его **администратором** с правами:
   - «Удаление сообщений»;
   - «Блокировка участников».
3. Если спам идёт в комментариях канала — добавьте бота в **привязанную
   группу обсуждения** (именно там живут комментарии).

## 4. Уберите старых «спам-ботов»

Бот не может удалить другого администратора — это делается вручную:
**Группа → Управление группой → Администраторы** → выберите старого бота →
«Снять с должности». Снять админа может владелец или тот, кто его назначал.

## Как бот решает, что удалять

| Ситуация | Реакция |
|---|---|
| Ссылка на сайт **не из** `TRUSTED_DOMAINS` | Удаление. Новичок (<5 мин в чате) — сразу бан |
| Ссылка на доверенный сайт (YouTube, VK, Яндекс…) | Не трогает |
| Слово из `SPAM_KEYWORDS` («заработок», «крипта»…) | Удаление; новичок — бан |
| Мат | Удаление; после 5-го раза — мьют на 10 мин |
| Больше 6 сообщений за 10 секунд | Мьют на 15 мин |
| Админы | Бот их не проверяет вообще |

## Настройки

Все настройки — в начале файла `bot.py` (блок «НАСТРОЙКИ»):

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `DELETE_BAD_LINKS` | `True` | Удалять ссылки вне белого списка |
| `TRUSTED_DOMAINS` | список | Доверенные сайты — ссылки на них не удаляются |
| `MAT_FILTER` | `False` | Удалять мат (выключено) |
| `MAT_MUTE_AFTER` / `MAT_MUTE_MINUTES` | `5` / `10` | Мьют после N матерных сообщений |
| `NEW_MEMBER_WATCH_SECONDS` | `300` | Сколько новичок «под наблюдением» |
| `BAN_NEWBIE_SPAMMER` | `True` | Банить новичка за спам (а не просто удалять) |
| `MUTE_NEW_MEMBERS_MINUTES` | `0` | >0 — новички молчат N минут после входа |
| `FLOOD_MAX_MESSAGES` | `6` | Лимит сообщений за `FLOOD_WINDOW_SECONDS` |
| `SPAM_PHRASES` | список | Стоп-фразы, удаляются сразу |
| `WORK_WORDS` + `HOOK_WORDS` | списки | Фейковые вакансии: связка «работа» + «личка/сумма» |

Фильтр понимает маскировку: латинские двойники букв (`зapaбoтoк`),
цифры вместо букв (`зарaбoтoк` с нулём) и буквы через пробел (`з а р а б о т о к`).

Команда `/antispam` в группе (только для админов) показывает статистику.

## Бесплатный хостинг (бот не зависит от вашего ПК)

### Вариант 1 — Render + UptimeRobot (проще всего, без карты)

1. Создайте аккаунт на [github.com](https://github.com) → создайте **приватный**
   репозиторий (Private!) → загрузите туда через веб-интерфейс файлы
   `bot.py`, `requirements.txt`, `render.yaml` (файл `token.txt` НЕ загружать!).
2. Зайдите на [render.com](https://render.com) через GitHub → **New → Web Service** →
   выберите репозиторий → Render сам прочитает `render.yaml`.
3. В настройках сервиса добавьте переменную окружения `BOT_TOKEN` = токен бота.
4. После деплоя скопируйте URL сервиса (вида `https://antispam-bot-xxxx.onrender.com`).
5. Зарегистрируйтесь на [uptimerobot.com](https://uptimerobot.com) (бесплатно) →
   **Add Monitor → HTTP(s)** → вставьте URL → интервал 5 минут.
   Это не даст бесплатному инстансу засыпать.

### Вариант 2 — ClawCloud Run (без карты, нужен GitHub старше 180 дней)

1. Войдите на [clawcloud.run](https://clawcloud.run) через GitHub — дают $5/мес бесплатно.
2. **App Launchpad → Create App** → выберите репозиторий с ботом (см. шаг 1 выше)
   или образ, собранный из `Dockerfile` (он уже в папке).
3. Переменные окружения: `BOT_TOKEN` = токен, `PORT` = `8080`; откройте порт 8080.

### Вариант 3 — Oracle Cloud Always Free (бесплатный VPS навсегда)

Настоящий VPS бесплатно, но при регистрации нужна банковская карта
(российские карты обычно отклоняет). Если получится зарегистрироваться —
дальше инструкция из раздела «Пересборка на VPS» ниже.

После успешного деплоя в облако удалите локальную копию из автозагрузки
(файл `antispam-bot.vbs` в папке автозапуска) и завершите локальный процесс —
бот не должен работать в двух местах с одним токеном.

## Перенос на платный VPS (работа 24/7)

Подойдёт самый дешёвый VPS (Timeweb, Selectel, Aeza, reg.ru — от ~150–300 ₽/мес)
с Ubuntu 22.04/24.04. Дальше на сервере:

```bash
sudo apt update && sudo apt install -y python3 python3-pip
sudo mkdir -p /opt/antispam-bot
# скопировать bot.py, requirements.txt, token.txt и antispam-bot.service
# в /opt/antispam-bot (например, через scp или WinSCP)
cd /opt/antispam-bot
sudo pip3 install -r requirements.txt
sudo cp antispam-bot.service /etc/systemd/system/
sudo systemctl enable --now antispam-bot
```

Проверка: `sudo systemctl status antispam-bot` — должно быть `active (running)`.
Логи: `sudo journalctl -u antispam-bot -f`.

После этого бот на ПК можно выключить, чтобы не было двух копий одновременно.
